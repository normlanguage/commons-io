# Apache Commons IO

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration is in `commons/io/module.norm`, which determines the pinned Maven root artifact, public adapter API, and locally audited JAR. The current runnable entry point is [acceptance example](examples/sample/commons/io/Main.norm). The complete JAR census is in the NAR's `binding/java-api.json`; the published API is in `module.json` under `jar.api`.

[Runnable samples](samples/README.md) demonstrate the library as an external Norm dependency.
